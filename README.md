# barangku

Rusak? Benerin dulu, jangan buang.

barangku connects people with broken laptops and phones to trusted independent repair technicians nearby. Customers can search, compare price ranges, book a repair, and track it. All UI text is in informal Bahasa Indonesia.

## Menjalankan project

1. Instalasi dependensi:
```bash
npm install
```

2. Menjalankan server development:
```bash
npm run dev
```

3. Build aplikasi untuk produksi:
```bash
npm run build
```

4. Menjalankan preview build produksi:
```bash
npm run preview
```
